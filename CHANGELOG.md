# Changelog

## 1.2.0

- Plugin ID is now `io.github.jacueblol.wallpaper-library`.
- First-run screen with a guided, category-by-category download of dharmx/walls.
- `libraryDir` setting is respected by the CLI and the Style menu rows too.
- Default library moved to `~/.config/omarchy/wallpapers/dharmx-walls`.
- Notification when a category is too large for the image picker.
- Menu rows handle category names with quotes and spaces; `install-menu` only
  touches its own block.
- Cover cache is kept per library folder.

## 1.1.0

- Category grid with cover images, current wallpaper preview, search,
  keyboard navigation, and right-click random.

## 1.0.0

- First release: category list in the bar, random wallpaper, Style menu rows.
